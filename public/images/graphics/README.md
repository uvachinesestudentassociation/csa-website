# Graphic Art Elements

Decorative and illustrative assets served at `/images/graphics/*`.

Use this folder for logos, icons, illustrations, banners, and other non-photo graphics (PNG/SVG/WebP recommended for transparency).

## Usage

Reference files from site code or CSS:

```tsx
<Image src="/images/graphics/example.png" alt="" width={120} height={120} />
```

```css
background-image: url("/images/graphics/example.png");
```
